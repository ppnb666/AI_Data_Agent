# AI_Data_Agent

基于 Python 的智能数据分析 Agent，
实现 Excel 数据读取、清洗和统计分析。

## 项目介绍

本项目用于帮助用户快速分析业务数据，
减少手工 Excel 数据处理工作。

## 当前功能

### Excel 数据分析

- 支持 Excel 文件读取
- 自动查看数据结构
- 数据统计分析
- 按字段聚合计算

## 技术栈

- Python
- pandas
- openpyxl
- Git

## 环境安装

安装依赖：

pip install -r requirements.txt


## 使用方法

运行：

python main.py
